# Спецификация REST API «Lumière Cinema» (API Reference & RBAC)

Документ описывает архитектуру RESTful API для онлайн-сервиса кинотеатра Lumière Cinema в соответствии с требованиями **Задания 3**.

---

## 1. Общие принципы и архитектура

- **Базовый URL**: `http://localhost:3000/api/v1`
- **Формат данных**: `application/json; charset=utf-8`
- **Аутентификация**: Передача JWT-токена в заголовке запроса:
  ```http
  Authorization: Bearer <access_token>
  ```
- **Стандартные коды HTTP ответов**:
  - `200 OK` — Успешное выполнение запроса с возвратом данных.
  - `201 Created` — Успешное создание сущности.
  - `400 Bad Request` — Ошибка валидации входных параметров.
  - `401 Unauthorized` — Токен отсутствует или недействителен.
  - `403 Forbidden` — У пользователя недостаточно прав (роли).
  - `404 Not Found` — Запрашиваемый ресурс не найден.
  - `409 Conflict` — Конфликт бизнес-логики (например, место на сеанс уже выкуплено, овербукинг).
  - `500 Internal Server Error` — Внутренняя ошибка сервера.

## 2. Ролевая модель доступа (RBAC Matrix)

Система поддерживает 5 уровней доступа:

| Роль | Описание |
| :--- | :--- |
| **Guest (Public)** | Неавторизованный пользователь: просмотр афиши, фильмов, расписания, отзывов и свободных мест. |
| **Customer** | Зарегистрированный зритель: бронирование билетов, просмотр личных заказов, написание отзывов. |
| **Cashier** | Кассир кинотеатра: продажа билетов в кассе, проверка броней по коду, подтверждение оплаты. |
| **Manager** | Менеджер репертуара: управление сеансами, добавление фильмов, модерация отзывов, отчеты. |
| **Admin** | Системный администратор: полный доступ к залам, пользователям, ролям и удалению данных. |

## 3. Каталог маршрутов и спецификация методов

### 3.1. Аутентификация и пользователи (`/auth`)

#### `POST /auth/register`
- **Роли**: `Guest (Public)`
- **Описание**: Регистрация нового зрителя.
- **Тело запроса**:
  ```json
  {
    "email": "ivanov@mail.ru",
    "password": "Password123!",
    "firstName": "Иван",
    "lastName": "Иванов",
    "phone": "+7 (999) 123-45-67"
  }
  ```
- **Ответ `201 Created`**:
  ```json
  {
    "token": "eyJhbGciOiJIUzI1NiIsIn...",
    "user": {
      "id": "c1f72a44-...",
      "email": "ivanov@mail.ru",
      "firstName": "Иван",
      "lastName": "Иванов",
      "role": "CUSTOMER"
    }
  }
  ```

#### `POST /auth/login`
- **Роли**: `Guest (Public)`
- **Описание**: Вход в систему по email и паролю.
- **Тело запроса**:
  ```json
  {
    "email": "customer@lumiere.ru",
    "password": "user123"
  }
  ```
- **Ответ `200 OK`**:
  ```json
  {
    "token": "eyJhbGciOiJIUzI1NiIsIn...",
    "user": {
      "id": "u-101",
      "email": "customer@lumiere.ru",
      "role": "CUSTOMER"
    }
  }
  ```

#### `GET /auth/me`
- **Роли**: `Customer`, `Cashier`, `Manager`, `Admin`
- **Описание**: Получение профиля текущего пользователя по JWT.
- **Ответ `200 OK`**: профиль пользователя и роль.

---

### 3.2. Каталог фильмов и жанров (`/movies`, `/genres`)

#### `GET /movies`
- **Роли**: `Guest (Public)`
- **Параметры строки (Query params)**:
  - `genreId` (число) — фильтр по жанру
  - `search` (строка) — текстовый поиск по названию
  - `page`, `limit` — пагинация
- **Ответ `200 OK`**:
  ```json
  {
    "total": 3,
    "page": 1,
    "items": [
      {
        "id": "m-101",
        "title": "Джон Уик 4",
        "durationMinutes": 169,
        "releaseYear": 2023,
        "ageRating": "18+",
        "rating": 8.2,
        "posterUrl": "https://image.tmdb.org/...",
        "genres": ["Боевик"]
      }
    ]
  }
  ```

#### `GET /movies/:id`
- **Роли**: `Guest (Public)`
- **Описание**: Детальная карточка фильма, жанры, актуальные сеансы и отзывы.

#### `POST /movies`
- **Роли**: `Manager`, `Admin`
- **Описание**: Добавление новой кинокартины в каталог.
- **Тело запроса**:
  ```json
  {
    "tmdbId": 603692,
    "title": "Джон Уик 4",
    "originalTitle": "John Wick: Chapter 4",
    "description": "...",
    "durationMinutes": 169,
    "releaseYear": 2023,
    "ageRating": "18+",
    "genreIds": [1, 2]
  }
  ```
- **Ответ `201 Created`**.

#### `DELETE /movies/:id`
- **Роли**: `Admin`
- **Описание**: Удаление фильма из системы (с каскадной очисткой связей).

---

### 3.3. Кинозалы и места (`/halls`)

#### `GET /halls`
- **Роли**: `Guest (Public)`
- **Описание**: Список всех активных кинозалов кинотеатра.

#### `GET /halls/:id/seats`
- **Роли**: `Guest (Public)`
- **Описание**: Схема зала со всеми рядами, номерами мест и их категориями (`STANDARD`, `VIP`).

#### `POST /halls`
- **Роли**: `Admin`
- **Описание**: Создание нового зала и генерация координатной сетки мест.

---

### 3.4. Сеансы и статус занятости мест (`/sessions`)

#### `GET /sessions`
- **Роли**: `Guest (Public)`
- **Параметры**:
  - `date` (`YYYY-MM-DD`) — дата сеанса
  - `movieId` — фильтр по фильму
  - `hallId` — фильтр по залу
- **Ответ `200 OK`**: список сеансов с временем начала, залом и ценой.

#### `GET /sessions/:id/seats-availability`
- **Роли**: `Guest (Public)`
- **Описание**: Схема зала для выбранного сеанса с указанием статуса каждого кресла (`FREE` или `BOOKED`).
- **Ответ `200 OK`**:
  ```json
  {
    "sessionId": "s-101",
    "movieTitle": "Джон Уик 4",
    "hallName": "Зал 1 — IMAX Laser",
    "basePrice": 650.00,
    "seats": [
      {
        "seatId": "st-1",
        "row": 1,
        "number": 1,
        "type": "STANDARD",
        "isAvailable": true,
        "price": 650.00
      },
      {
        "seatId": "st-2",
        "row": 2,
        "number": 4,
        "type": "STANDARD",
        "isAvailable": false,
        "price": 650.00
      }
    ]
  }
  ```

#### `POST /sessions`
- **Роли**: `Manager`, `Admin`
- **Описание**: Добавление сеанса в расписание с проверкой на отсутствие наложения времени в одном зале.
- **Тело запроса**:
  ```json
  {
    "movieId": "m-101",
    "hallId": "h-1",
    "startTime": "2026-10-20T19:00:00Z",
    "basePrice": 650.00,
    "sessionType": "FORMAT_IMAX"
  }
  ```

### 3.5. Бронирование и билеты (`/bookings`)

#### `POST /bookings`
- **Роли**: `Customer`, `Cashier`
- **Описание**: Создание заказа на бронирование выбранных мест на конкретный сеанс. Защищено транзакцией и уникальным ограничением от одновременной покупки одних и тех же мест.
- **Тело запроса**:
  ```json
  {
    "sessionId": "s-101",
    "seatIds": ["st-10", "st-11"],
    "customerName": "Дмитрий Соколов",
    "customerEmail": "customer@lumiere.ru",
    "customerPhone": "+7 (999) 777-88-99"
  }
  ```
- **Ответ `201 Created`**:
  ```json
  {
    "bookingId": "b-101",
    "bookingCode": "LUM-2026-7841",
    "status": "CONFIRMED",
    "paymentStatus": "UNPAID",
    "totalAmount": 1300.00,
    "ticketsCount": 2,
    "expiresAt": "2026-10-20T18:45:00Z"
  }
  ```
- **Возможные ошибки**:
  - `409 Conflict`: `{"error": "SEATS_ALREADY_BOOKED", "message": "Одно или несколько мест уже заняты"}`

#### `GET /bookings/my`
- **Роли**: `Customer`
- **Описание**: История заказов текущего авторизованного пользователя.

#### `GET /bookings/verify/:code`
- **Роли**: `Cashier`, `Manager`, `Admin`
- **Описание**: Быстрая валидация билета контролером или кассиром по коду брони (`LUM-2026-7841`).

#### `POST /bookings/:id/confirm-payment`
- **Роли**: `Cashier`, `Admin`
- **Описание**: Проведение оплаты в кассе или фиксация вебхука эквайринга. Статус заказа меняется на `PAID`.

#### `POST /bookings/:id/cancel`
- **Роли**: `Customer` (только свои брони), `Cashier`, `Admin`
- **Описание**: Отмена бронирования и освобождение мест для повторной продажи.

### 3.6. Отзывы зрителей (`/reviews`)

#### `GET /movies/:movieId/reviews`
- **Роли**: `Guest (Public)`
- **Описание**: Просмотр опубликованных отзывов зрителей о фильме.

#### `POST /movies/:movieId/reviews`
- **Роли**: `Customer`
- **Описание**: Публикация отзыва и оценки (1..5) после просмотра.
- **Тело запроса**:
  ```json
  {
    "rating": 5,
    "text": "Потрясающая динамика и звук в IMAX зале!"
  }
  ```

#### `PATCH /reviews/:id/moderate`
- **Роли**: `Manager`, `Admin`
- **Описание**: Скрытие или одобрение отзыва модератором.

---

### 3.7. Диагностика и проверка доступности (`/health`)

#### `GET /api/health`
- **Роли**: `Guest (Public)`
- **Описание**: Проверка работоспособности бэкенда и активности соединения с PostgreSQL.
- **Ответ `200 OK`**:
  ```json
  {
    "status": "UP",
    "database": {
      "status": "CONNECTED",
      "provider": "PostgreSQL"
    },
    "timestamp": "2026-10-19T05:30:00Z"
  }
  ```
